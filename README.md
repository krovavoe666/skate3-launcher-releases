# Skate 3 Launcher

Лаунчер для PC-порта Skate 3: свои персонажи, модели из Garry's Mod, настройки графики и игра с другом по локальной сети.

Скачай `Skate3Launcher-Setup-*.exe` из [последнего релиза](https://github.com/krovavoe666/skate3-launcher-releases/releases/latest) и запусти. Новые версии лаунчер ставит сам, при запуске он предложит обновиться.
